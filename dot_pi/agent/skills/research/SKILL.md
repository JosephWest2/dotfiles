# Research

Research the topic supplied with this skill command. If no topic was supplied, use the clear research request already present in the conversation; if none exists, ask what the user wants researched.

Use authoritative, current sources where possible, cross-check important claims, and distinguish established facts from uncertainty or opinion. Return a concise synthesis, key findings, relevant tradeoffs, and links or citations to the sources. Do not modify project files unless the user explicitly asks.
