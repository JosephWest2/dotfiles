# Global PI Agent Instructions

- Ask clarifying questions if needed before implementing any changes.
- Don't always take the user's assumptions as true, if they don't seem correct, verify them and then bring the issue to the user before continuing.
- When working, if you encounter unforseen tradeoffs, ask questions before proceeding to ensure that the user is okay with making those tradeoffs.
- If the changes required to complete a task or commands required greatly expand the scope of the task, ask for confirmation from the user before proceeding.
